# 3.0.4 版修正说明

## 3.0.4 无人操作时课程自动接续

- 修复个人中心处于后台、窗口最小化或锁屏状态后，已完成课程不能继续进入下一门的问题。
- 取消个人中心必须处于可见状态才能打开课程的限制，仍使用跨标签页课程锁防止重复打开。
- “正在学习”锁的失效时间由10分钟延长到6小时，课程页正常运行时持续续期；课程完成或关闭仍会主动更新锁状态。
- 桌面端在自动学习开启期间调用 Windows 系统接口阻止系统自动睡眠，不阻止显示器关闭；停止学习或退出桌面端时恢复原有设置。
- 3.0.4 使用新的锁标识，升级后不会继承3.0.3遗留的活动锁。

## 3.0.3 后台标签页冲突修正

- 修复用户切换到其他标签页后，学习页心跳受浏览器节流影响、个人中心误判课程已关闭的问题。
- 个人中心处于后台时禁止打开课程；重新切回个人中心后才允许执行新课程操作。
- “正在打开”锁延长至2分钟，“正在学习”锁延长至10分钟，课程页仍会持续续期。
- 课程页正常关闭或离开时主动标记关闭，使个人中心能够刷新列表并继续。
- 3.0.3 使用新的锁标识，升级后不会被旧版遗留的活动锁继续阻塞。
- 模拟个人中心连续轮询并切换到后台后，没有再次点击课程入口；模拟课程页关闭时，活动锁能够立即转为“已关闭”。

## 网上专题班适配边界

- 当前账号没有临时班级列表，无法核实“全部班级”与班级课程页的真实 DOM、网址和完成状态字段，因此本版不猜测选择器或自动点击班级。
- 待临时任务出现后，使用真实页面截图和网址增加“班级列表 → 班级课程列表”分支；打开单门课程后的播放、切换小节和完成检测可复用现有逻辑。

## 3.0.2 防止无限新开标签页

- 修复个人中心每隔数秒重复点击同一课程、持续新开课程标签页的问题。
- 新增同源标签页共享课程锁，状态分为“正在打开、正在学习、已完成”。
- 课程详情页定时刷新活动状态；个人中心检测到活动课程时不再点击任何课程。
- 课程完成后清除锁并刷新课程列表；课程标签页被意外关闭时，锁在超时后自动释放。
- 模拟个人中心连续执行 20 次轮询，课程入口只触发 1 次；模拟课程完成后，列表刷新只触发 1 次。

## 3.0.1 补充修正

- “前往个人中心”不再直接调用不确定的 Windows 默认浏览器，改为优先定位并启动 Microsoft Edge。
- 油猴脚本离线时，“刷新当前网页”不再记录为已经发送，而是明确提示在浏览器中按 `Ctrl+F5`。
- 开始、停止命令在脚本离线时明确标记为排队状态。
- 状态栏直接提示应在安装油猴的浏览器中刷新页面。

## 已确认的问题

1. `启动干部网院学习助手.bat` 把解释器固定为 `C:\Python313\pythonw.exe`，Python 安装位置不同时必然启动失败。
2. 无黑框 VBS 仅调用 PATH 中的 `pythonw`，找不到时直接静默退出，没有可见提示。
3. 桌面端依赖 `127.0.0.1:7791` 上的 AgentLimb 服务，但原压缩包未提供该服务或安装程序。
4. 桌面端与油猴脚本没有通信代码，两者实际无法同步开始、停止、课程列表或进度。
5. 桌面端额外依赖 `requests`，说明中没有安装步骤。
6. 油猴脚本只在初始化时判断一次页面类型，站内单页跳转后不会重新挂载相应处理逻辑。
7. 进入课程后用于防重复跳转的状态不会复位，可能导致后续课程无法继续。
8. 播放检测会反复点击普通播放按钮；播放器按钮具备播放/暂停双态时，可能造成反复切换。
9. 课程标题缺失时直接调用 `.slice()`，会让定时任务抛错并停止。
10. 脚本缺少清晰的启动标识；浏览器未授权执行用户脚本时，用户看到的现象只是“没有任何反应”。

## 本次修正

- 启动器改为自动查找 Python Launcher、PATH 和当前用户常见 Python 安装目录，不再写死版本和路径。
- 桌面端内置仅监听 `127.0.0.1` 的本机桥接服务，移除 AgentLimb 和 `requests` 依赖。
- 桌面端与油猴脚本通过状态上报、运行命令和刷新命令真正联通；首选原端口，冲突时自动使用备用端口。
- 油猴脚本在登录页、个人中心和课程页均显示隔离样式的 v3.0 悬浮窗。
- 增加站内路由持续识别、动作冷却、空标题保护、课程和小节选择器回退。
- 只在视频确实暂停时触发播放，缩小自动点击弹窗按钮的范围。
- 课程完成时优先返回个人中心；只有课程页由其他窗口打开时才尝试关闭。
- 脚本可脱离桌面端独立运行，桌面端关闭不会中断脚本自身逻辑。

## 需要在实际账号环境确认

当前环境无法登录个人账号，因此课程页面的最新 DOM 结构、平台进度写回和首次自动播放仍需在实际登录后的页面确认。若右下角 v3.0 悬浮窗已出现但课程无法识别，请提供该页面网址和截图；如果悬浮窗完全不出现，应先检查 Edge/Tampermonkey 的“允许用户脚本”权限。
