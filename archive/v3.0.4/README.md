# 青岛干部网络学院学习助手 3.0.4

本包包含两个可以配合使用、也可以分别使用的部分：

- `青岛干部网院自动刷课_油猴脚本.user.js`：网页端主体功能，可独立运行。
- `main.py`：可选桌面监控端，用于显示课程和进度，并向油猴脚本发送开始、停止、刷新命令。

3.0 版已移除旧版对 AgentLimb 的依赖，桌面端会自己启动仅限本机访问的桥接服务，也不再需要安装 `requests`。

3.0.1 版将“前往个人中心”改为优先使用 Microsoft Edge，避免 Windows 默认浏览器没有安装油猴；脚本离线时不再把刷新操作误报为“已发送”。

3.0.2 版增加跨标签页课程锁：同一时间只允许打开一门课程，课程学习页会持续报告存活状态，完成后个人中心才刷新并进入下一门；课程页意外关闭后，锁会自动超时释放。

3.0.3 版修复切换到其他标签页后可能再次打开课程的问题：个人中心只有在前台可见时才能打开课程，后台页面只等待；活动锁延长至适应 Edge 后台定时器节流的时间，并在课程页正常关闭时主动释放。

3.0.4 版修复电脑长时间无人操作时课程之间不能自动接续的问题：个人中心在后台也可进入下一门课程，活动锁延长至6小时并由课程页持续续期；桌面端在自动学习开启期间阻止 Windows 进入系统睡眠，但不阻止显示器关闭。

从旧版更新时，请先暂停旧脚本并关闭重复打开的课程标签页，只保留一个个人中心；随后用 3.0.4 脚本覆盖旧脚本并刷新网页。若同时使用桌面端，也请替换完整程序包。

## 一、先让油猴脚本真正运行

1. 在 Edge 中安装并启用 Tampermonkey（篡改猴）。
2. 打开 `edge://extensions`，进入 Tampermonkey 的“详细信息”。
3. 打开“允许用户脚本”；如果页面里没有该开关，就在扩展页面打开“开发人员模式”。
4. 在 Tampermonkey 中重新安装本包的 `.user.js` 文件，确认脚本开关为“启用”。
5. 打开或刷新 `https://www.qdgbjy.gov.cn/`。

页面右下角出现“青岛网院助手 v3.0”悬浮窗，才表示脚本已经执行。登录页也会显示悬浮窗。若悬浮窗完全不出现，先检查第 2～4 步；这属于浏览器未授权执行用户脚本，不是课程选择器问题。

必须在安装油猴的同一个浏览器、同一个用户配置中打开网站。360 浏览器应使用“极速模式”，Edge 不应使用 IE 模式；兼容模式下扩展脚本不会在当前页面执行。

## 二、只用油猴脚本

油猴脚本默认开启自动学习。登录后进入“个人中心—我的课程—正在学习的课程”，脚本会识别课程、小节和进度。右下角按钮可以随时暂停或恢复。

桌面端未打开时，悬浮窗显示“桌面端未连接”，不影响脚本独立运行。受浏览器自动播放规则影响，首次进入播放器时可能仍需手动点击一次播放按钮。

只使用油猴脚本时，Windows 一旦进入睡眠或休眠，浏览器和脚本都会暂停。需要长时间无人值守时，建议同时运行桌面端；桌面端会在自动学习开启期间保持系统唤醒，停止学习或关闭桌面端后恢复原有睡眠设置。

## 三、同时使用桌面端

桌面端需要 Python 3.10 或更高版本，Windows 官方 Python 安装包通常自带 Tk 图形组件。安装 Python 时建议勾选 `Add python.exe to PATH`。

- 推荐：双击 `双击启动助手(无黑框).vbs`。
- 排错：双击 `启动干部网院学习助手.bat`，可以看到缺少 Python 等提示。
- 可选：双击 `创建桌面快捷方式.bat` 创建桌面入口。

启动器不再写死 `C:\Python313\pythonw.exe`，会依次查找 Python Launcher、PATH 和当前用户的常见 Python 安装目录。

正确顺序：

1. 启动桌面端。
2. 在 Edge 打开青岛干部网络学院并刷新页面。
3. 页面悬浮窗应显示“桌面端已连接”，桌面端应显示“油猴脚本：在线连通”。
4. 通过网页悬浮窗或桌面端按钮开始、停止或刷新。

## 四、仍然没有反应时

- 网站上没有右下角悬浮窗：检查 Tampermonkey 是否启用，以及 Edge 是否允许执行用户脚本。
- 有悬浮窗、桌面端显示未连接：先启动桌面端，再刷新网站；关闭可能占用本机端口的旧版助手。
- 桌面端已启动但网页没有悬浮窗：确认不是由另一个默认浏览器、访客配置、无痕窗口或兼容模式打开的网站。
- 桌面端提示找不到 Python：安装 Python 3，或只使用油猴脚本。
- 有悬浮窗但识别不到课程：保留当时的网址和网页截图，以便按网站最新页面结构更新选择器。

## 五、网上专题班（临时任务）

当前版本暂未自动进入“网上专题班—全部班级”。没有真实班级任务时，可以先编写和模拟列表逻辑，但无法确认网站实际使用的网址、页面结构、班级完成状态及进入课程列表的点击方式。为避免误点其他班级，待任务出现后，请保留“全部班级”页面、班级内课程列表页面的截图和网址，再按真实页面增加该分支；班级内的单门课程仍可复用现有学习流程。

请在符合单位制度和网站使用规则的前提下使用，并留意页面提示与学习记录是否正常保存。
