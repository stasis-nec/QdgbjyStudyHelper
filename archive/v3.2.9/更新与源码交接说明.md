# 青岛干部网院学习助手更新与源码交接说明（v3.2.9）

## 本次修正

长时间学习后，“跳过当前课程”变灰不一定表示脚本识别成普通课程。专题班列表页检测到活动课程锁时会提前退出，当前可跳过目标可能为空；按钮此前仅依据该内存目标启用。关闭网页后重新进入会重新计算目标，因此按钮颜色可能恢复。

v3.2.9 在列表页优先用活动课程锁对应的专题班返回记录（课程 ID、名称）确定跳过目标；记录缺失时仅允许课程接口中名称唯一匹配的课程，避免误跳相邻或同名课程。专题班课程页同时依据 URL 的 `trainClassId` 判断按钮是否可用，即使页面状态暂时未识别为 detail，也可作用于当前课程。仍只有用户单击按钮才保存一条跳过记录；关闭窗口不会自动跳过。若网站曾在旧版本保存多条错误记录，可用“恢复上次跳过”逐条撤销。

普通课程继续走独立的 v3.0.4 页面识别、选课、播放、完成、返回和课程锁逻辑，本版未调整普通课程代码路径。

## 操作与源码

- `青岛干部网院自动刷课_油猴脚本.user.js` 是油猴源码；`main.py` 是可选桌面端源码；版本均为 3.2.9。完整包另含 Windows 启动脚本、README 和 SHA256 校验文件。
- 手动选择普通课程或专题班；专题班的“点击参加”由用户完成。专题班课程按 `getCourseDetailList` 的 ID、进度与分页顺序选择，完成后刷新列表并恢复页码，手动跳过独立持久保存。
- 网站分页诊断样本每页 8 条、共 25 条，下一页按钮为 `.isQiantai.pagination-container .el-pagination button.btn-next`。旧版“完成待更新”记录不再读取。

已通过 JavaScript 语法、Python 编译、活动课程锁目标回归检查、SHA256 和压缩包校验；尚未在用户网站实测 v3.2.9。后续更新只保留本合并说明和 README，并交付完整源码。
