# 青岛干部网络学院学习助手

网页端油猴脚本 + 可选桌面监控端的学习辅助工具，适用于青岛干部网络学院（https://www.qdgbjy.gov.cn/）。

|---|---|---|
| 根目录 | v3.3.5（当前） | 在 3.2.9 基础上增加故障诊断、日志落盘、有限重试；重点修复切换账号后的课程状态冲突、冻结标签恢复误暂停等问题 |

## 文件组成（v3.3.5）

- `青岛干部网院自动刷课_油猴脚本.user.js` —— 网页端主体功能，可独立运行
- `main.py` —— 可选桌面监控端：显示课程和进度，向油猴脚本发送开始/停止/刷新命令
- `启动干部网院学习助手.bat` / `双击启动助手(无黑框).vbs` / `创建桌面快捷方式.bat` —— Windows 启动脚本
- `更新与源码交接说明.md` —— 版本更新记录
- `故障诊断与日志说明.md` —— 故障诊断与日志落盘说明
- `版本3.3.1_修改与测试说明.md` ～ `版本3.3.5_修改与测试说明.md` —— 各版本修改与测试说明
- `tests/` —— 离线模拟测试脚本（账号切换、守护、桥接、看门狗）

## 使用方法

1. 在 Edge 安装并启用 Tampermonkey（篡改猴），打开扩展「允许用户脚本」开关。
2. 用 Tampermonkey 安装 `青岛干部网院自动刷课_油猴脚本.user.js`。
3. 打开或刷新青岛干部网络学院网站，页面右下角出现悬浮窗即表示脚本已运行。
4. 登录后在悬浮窗手动选择模式：
   - **普通课程**：只学习个人中心「我的课程—正在学习的课程」
   - **网上专题班**：先手动点击「点击参加」进入班级课程列表，脚本逐门学习未完成课程
5. 可选：双击 `双击启动助手(无黑框).vbs` 启动桌面端（需 Python 3.10+），桌面端在自动学习期间阻止 Windows 进入睡眠，并将诊断历史写入本地日志文件。

## 注意事项

- 请在符合单位制度和网站使用规则的前提下使用，并留意页面提示与学习记录是否正常保存。
- 升级到 3.3.5 时请先关闭旧课程子标签；切换账号后如出现旧课程状态冲突，可用悬浮窗新增的「切换账号后清理旧课程状态」按钮清理（只清理本地临时锁，不改变平台记录和学习进度）。
